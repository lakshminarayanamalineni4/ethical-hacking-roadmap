# Module 9 — Capstone and portfolio

**Weeks:** 22–24  
**Outcome:** Deliver three small, defensible assessments with reproducible evidence and remediation.

| ID | Submodule | Concepts |
|---|---|---|
| 9.1 | Web app assessment | Scope, map routes, select test cases, reproduce lab findings, remediate and retest |
| 9.2 | API assessment | Role/tenant matrix, object/function authorization, validation and rate limits |
| 9.3 | Cloud/container review | IAM, network exposure, storage, logging, Docker image and secret handling |
| 9.4 | Professional reporting | Executive summary, scope, methodology, findings, severity, evidence, fixes, limitations |
| 9.5 | Portfolio hygiene | Remove secrets and personal data; publish only sanitized labs, code and reports |

## Deliverables
1. Web security report for local OWASP Juice Shop or your own deliberately vulnerable app.
2. FastAPI API security test suite and remediation notes.
3. Cloud/container configuration review using a test environment or local container lab.
4. Reusable security checklist for pull requests and architecture reviews.

## Exit criteria
Three sanitized portfolio artifacts exist, each showing the issue, safe evidence, fix and retest.
