# Roadmap overview

## Learner profile and constraints
- Starting point: intermediate programming/backend development; cybersecurity foundations are to be built from the beginning.
- Goal: systematic ethical hacking knowledge and practical, documented security-testing skills.
- Environment: Windows 10/11, WSL2 Ubuntu, optional Kali VM and Docker local labs.
- Cadence: 1–2 hours/day, 5–6 days/week, with one lighter review/rest day.
- Duration: 24 weeks as a guide; learning outcomes take priority over calendar dates.
- Engineering context: APIs, databases, authentication, RAG/LLM systems, Docker and AWS.

## Guiding principles
1. Follow the module order; do not jump to exploitation tools before understanding networks, operating systems and target technology.
2. Pair offensive understanding with defensive remediation.
3. Use only authorized targets and isolated training environments.
4. Measure progress by explanation, repeatable tests, secure fixes and evidence—not tools installed or commands memorized.
5. Apply security proportionately in day-to-day engineering.

## Learning loop
Understand → Trace → Implement → Test → Document → Revise. See [the detailed workflow](../guides/learning-workflow.md).

## Completion standard
Explain in your own words; map the data/request flow and trust boundaries; perform a safe hands-on exercise; test normal, invalid, unauthorized and boundary cases; describe remediation; save sanitized evidence; recall and repeat after a delay.
