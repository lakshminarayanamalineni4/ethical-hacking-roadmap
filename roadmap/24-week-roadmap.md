# 24-week roadmap

| Module | Weeks | Main outcome |
|---|---:|---|
| 1. Networking foundations | 1–3 | Explain DNS, TCP/IP, ports, HTTP(S), routing and packet flow. |
| 2. Linux and Windows fundamentals | 4–5 | Navigate systems; inspect processes, services, permissions and logs. |
| 3. Security foundations | 6–7 | Explain CIA, risk, identity, cryptography, sessions and controls. |
| 4. Reconnaissance and scanning | 8–9 | Inventory assets/services in an authorized lab and interpret results. |
| 5. Web application security | 10–13 | Test and fix common web risks in a local training application. |
| 6. API security | 14–16 | Assess identity, authorization, validation, abuse controls and API design. |
| 7. Network security assessment | 17–19 | Assess an isolated lab, validate findings safely and report remediation. |
| 8. Cloud and container security | 20–21 | Apply least privilege and secure AWS, network, storage, logging and containers. |
| 9. Capstone and portfolio | 22–24 | Deliver web, API and cloud/container assessments with professional reports. |

## Suggested weekly rhythm
| Session | Time | Activity | Output |
|---|---:|---|---|
| Learn | 25–30 min | Read/watch one concept; prefer official docs. | Short notes |
| Explain | 10–15 min | Recall without notes; draw a flow or give an example. | 5–10 line explanation |
| Implement | 35–45 min | Perform a safe lab or add a defensive control locally. | Code/commands/evidence |
| Test | 10–15 min | Try negative cases and verify behavior. | Test result |
| Review | 5–10 min | Record confusion, fixes and next review date. | Learning-log entry |

Use this as a suggested 1–2 hour session template; adjust when a lab needs more time. Do not advance solely because a week has ended.
