# Source material

The initial structure and curriculum in this repository are derived from the user's document **Ethical_Hacking_Roadmap_and_Progress_Tracker.docx** (17 pages).

The source plan specifies:
- Intermediate programming/backend experience, with cybersecurity foundations built from the beginning.
- Windows 10/11 with WSL2 Ubuntu, optional Kali VM and Docker-based local labs.
- 24-week sequence, studying 1–2 hours/day, 5–6 days/week.
- Nine modules, a repeatable Understand → Trace → Implement → Test → Document → Revise loop, D+1/D+7/D+30/D+90 revision and a Backend + AI security mapping.

This folder records provenance. Keep the original DOCX in a safe personal location; do not commit it if it contains private annotations or personal information. The module files are a structured, maintainable representation of the source plan, not a replacement for the original document.
