# Spaced revision tracker

Schedule reviews relative to the date first learned. If a review is weak (score 0–1), repeat the exercise and restart the short review cycle.

| Concept / ID | Learned date | D+1 date / score | D+7 date / score | D+30 date / score | D+90 date / score | Next action |
|---|---|---|---|---|---|---|
| | | | | | | |

## How to revise
- **D+1:** Recall key ideas without notes; answer three questions.
- **D+7:** Explain the flow and redo one small exercise.
- **D+30:** Solve a fresh scenario or write a test from memory.
- **D+90:** Connect the concept to an engineering task; update notes if needed.

## Score scale
0 = could not recall; 1 = needed notes/help; 2 = mostly recalled; 3 = explained and implemented independently. Aim for 2–3.
